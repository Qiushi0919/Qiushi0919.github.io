# 用户确认的作品集约定

最新确认：2026-10-07。用户新指令优先于此记录。

## 小项目访问

- “全部 / All Work”固定只显示论文与比赛，不显示 Codex Tidy、Boring Notch
  Focus、AltTab、MindMap 四个小项目；不加密码框，解锁后也不恢复到全部列表。
- “小项目 / Side Projects”未解锁时采用纯白、无外框／阴影／渐变的简约布局，
  不放蓝底卡片、锁图标或“私人作品集”标签。表单上方仅一行
  “暂不开放，输入密码后查看”，不显示有效期声明；按钮使用中性色。
  支持手机、深色模式、显示／隐藏密码、错误提示和返回全部作品。
- 使用用户指定密码，成功一次后在当前浏览器、当前域名保存 180 天；切换同域
  语言和详情、刷新自动恢复，恢复访问不重新计算期限。过期要求重新输入。
- 四个作品集详情页同样需要解锁，未解锁前不请求其图片。公开 HTML 内是
  AES-GCM 加密的页面，密码和构建密钥不进入公开文件；浏览器保存派生密钥
  与过期时间。构建密钥只在本地 `.private/side-project-access.json`，不得上传。
- 小项目列表和四个作品集详情不进入网站地图，锁定页面 noindex。
  已公开的独立项目网站、GitHub 仓库、素材及历史不会因作品集入口而变私有。

## 动态预览与加载

- 国内站和国际站、中英文、所有视图共用相同规则。
- 下载按 EECS → Intel 杯 → C 题排列；当前页面不存在的项目跳过。
  每项动画使用较小的 MP4 文件，完整下载后再进入下一个；同一页面的缩略图、
  放大播放器和重播共用同一 Blob 缓存和对象 URL，不重复请求。
- 首次等待以尽快开始播放为目标，不固定追求高并发。本机冷下载比较中，
  EECS 图片帧 25 文件约 6.5 MiB；1/4/8/25 并发总耗时都约 16 秒，
  MP4 约 1.3 MiB、约 2.1 秒。该测试不能代表用户手机上的实际等待时间。
- 动画和首图 URL 按素材内容生成版本，页面样式更新不使动画缓存地址失效。
- MP4 使用不可点击、静音、内联的隐藏解码器，画面输出到 Canvas；
  保留自定义播放和进度条，不暴露缩略图上的手机原生播放器操作区。
  EECS 首次完整出现在屏幕且下载准备好后自动播放。Intel/C 缩略图与放大
  副本只有用户点击播放才开始，加载准备仍按原队列进行。离屏、后台标签或被弹窗
  遮挡时暂停。MP4 播放速度及既有片段停留时间不变。
- 放大详情的其他图片、视频必须在页面上的动画缩略图全部完成或失败后加载。
  不用悬停、获得焦点或轻触提前抢占下载；关闭后尚未开始的详情加载取消。
  详情原始视频只准备元数据，播放仍由用户选择。
- 不再显示整页／列表加载提示、5 秒倒计时、转圈或任何可见的加载文字。
  页面立即显示。EECS、Intel 杯、C 题及放大副本统一在缩略图最顶边显示
  3 个视觉 CSS 像素高的矩形进度条，绝对定位，不预留顶部空白或增加行高。
  蓝色填充按实际接收字节推进，加载完成或失败即隐藏；未知文件大小才用
  无文字的移动线段。等待队列的项目只显示空轨道。重播按钮保留播放／重播
  播放标签，忙时阻止重复点击，不替换成“加载中”。
- 旧图片帧实现和原始素材保留为维护参考：其单项目最多 4 文件并发，
  采用连续前段及吞吐量估算开播；完整下载前不允许跳转到未缓冲位置。
- EECS 持续循环，无列表重播键；首图用横版流程图。第一轮总览 1.5 秒，
  从第二轮开始 2.7 秒。ALA–VMD 3.125 秒，输入整理 1.8 秒，
  BiTCN＋Attention 2.4 秒，结果 2.5 秒；4 次过渡各 0.55 秒。
  30fps 编码实际首轮约 13.533333 秒，后续约 14.733333 秒。
- Intel 六段依次 2.8、2.3、1.5、2.5、约 1.958333、2 秒。
  C 题三段各 2 秒。既有封面和 0.5 秒交叠过渡保留。
  含封面的实际文件长度约为 Intel 12.041667 秒、C 题 6.5 秒。
- Intel/C 点击播放一次后停回首图；按钮始终为 ▶ 播放，开始时从封面以外
  的第一幅演示播放。播放键半透明、无边框，播放期间隐藏，停留首图时不挡文字。
- 放大窗口顶部的动画使用自定义播放／暂停、可拖动进度条和时间显示。
  直接读取缩略图的同一 MP4 缓存，不另外下载，也不显示手机原生播放器控件。
- 视频缩略图和放大窗口顶部动画支持右键“下载视频”，只在右键时显示菜单，
  不增加常驻按钮、空白行或原生播放器。下载复用同一 MP4 Blob 和对象 URL；
  尚未准备好时等待既有 EECS → Intel → C 队列，失败允许重试。键盘可用
  Shift+F10 打开菜单，Escape 先关闭菜单；普通单击继续放大。

## 排版与弹窗

- 竞赛项目不设置 BibTeX／Cite 入口或引用格式区，包括英特尔杯独立项目网站；
  学术论文继续保留引用格式、复制与下载功能。

- 英文 Times New Roman，中文 Microsoft YaHei（微软雅黑），使用现有回退字体。
- 作者标记：† 共同一作，‡ 队长／项目负责人，* 指导教师／通讯作者。
  标记同样上标，不自画队长符号。学生、老师同一行，谢秋实名字加下划线。
- 全部、论文、比赛列表标题下仅保留点击说明与作者符号释义。中文为
  “单击左侧缩略图查看详情，单击作品标题或下方链接访问对应页面。
  （†共同第一作者。‡项目负责人。*通讯作者／竞赛指导教师。）”；英文采用
  “Click a thumbnail on the left to view details, or a title or link below to visit
  the corresponding page. (†Equal contribution. ‡Project lead.
  *Corresponding author / Competition advisor.)”。不再加作品分类总述。
- 比赛奖项仅保留主奖项：Intel 全国二等奖、C 题湖北赛区一等奖、嵌赛
  全国总决赛二等奖。删除“前 7.83%”、“华中科技大学该题目唯一省一队伍”
  和嵌赛“中部赛区一等奖 · 全国前3.97%”，中文与英文、首页与详情／关于我同步。
- Selected Work 下各作品分割线及页脚分割线采用 0.8px、#333333。
- 并排作品文字区与缩略图画面居中对齐，排除下方播放键的保留高度；
  手机概览按同样规则，单列大图视图不加此对齐余量。
- 平板简介保持居中照片在上、姓名和简介在下的布局；关于我页包含照片和 9 个图标。
- 关于我页的简介末尾、代表论文与项目上方放置醒目的蓝色返回按钮：中文
  “← 返回全部作品”，英文“← Back to All Work”，直接返回同语言首页的
  作品总览位置。手机点击高度至少 44 个视觉 CSS 像素，兼容键盘与深色模式。
- 深色模式的弹窗标题、副标题、关闭键采用清晰的浅色文字与深色背景。
- 放大窗口标题、关闭键吸顶；窗口内部滚动，不移动底层页面，关闭恢复原位置。
- 手机图片使用自然比例和高度，单列展示；小型 UI 对话框截图限制为 220 个
  视觉 CSS 像素宽，避免截图内文字过大。平板弹窗保留两侧、上下留白。

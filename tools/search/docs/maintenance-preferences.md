# 用户确认的作品集约定

最新确认：2026-10-06。用户新指令优先于此记录。

## 动态预览与加载

- 国内站和国际站、中英文、所有视图共用相同规则。
- 下载按 EECS → Intel 杯 → C 题排列；当前页面不存在的项目跳过。
  同一时刻只下载一个动画资源，完整缓冲一个项目后再加载下一个。
- 缩略图和放大弹窗共用压缩帧缓存，重播不重新下载。只保留少量解码画面，
  避免把整套动画展开到内存。
- 启动时“正在加载作品集”只覆盖作品标题下方的列表，导航、照片和简介正常显示，
  允许浏览上方和滚动页面。最多等待 5 秒；准备完成可以提前进入。
  超时后继续后台顺序加载。未缓冲完整的缩略图上方显示半透明转圈，完成即隐藏。
- 使用 Canvas 图片帧播放，避免触发手机原生播放器。完整缓冲且第一次完全
  出现在屏幕后才自动播放。离屏、后台标签或被弹窗遮挡时暂停。
- EECS 持续循环，无列表重播键；首图用横版流程图。第一轮总览 1.5 秒，
  从第二轮开始 2.7 秒。ALA–VMD 3.125 秒，输入整理 1.8 秒，
  BiTCN＋Attention 2.4 秒，结果 2.5 秒；4 次过渡各 0.55 秒。
  30fps 编码实际首轮约 13.533333 秒，后续约 14.733333 秒。
- Intel 六段依次 2.8、2.3、1.5、2.5、约 1.958333、2 秒。
  C 题三段各 2 秒。既有封面和 0.5 秒交叠过渡保留。
  含封面的实际文件长度约为 Intel 12.041667 秒、C 题 6.5 秒。
- Intel/C 自动播放一次后停回首图；手动重播从封面以外的第一幅演示开始。
  重播键半透明、无边框，播放期间隐藏，停留首图时不挡文字。
- 放大窗口顶部的动画使用自定义播放／暂停、可拖动进度条和时间显示。
  直接读取缩略图的同一套缓存，不另外下载 MP4，不触发手机原生播放器。

## 排版与弹窗

- 英文 Times New Roman，中文 Microsoft YaHei（微软雅黑），使用现有回退字体。
- 作者标记：† 共同一作，‡ 队长／项目负责人，* 指导教师／通讯作者。
  标记同样上标，不自画队长符号。学生、老师同一行，谢秋实名字加下划线。
- Selected Work 下各作品分割线及页脚分割线采用 0.8px、#333333。
- 平板简介保持居中照片在上、姓名和简介在下的布局；关于我页包含照片和 9 个图标。
- 放大窗口标题、关闭键吸顶；窗口内部滚动，不移动底层页面，关闭恢复原位置。
- 手机图片使用自然比例和高度，单列展示；小型 UI 对话框截图限制为 220 个
  视觉 CSS 像素宽，避免截图内文字过大。平板弹窗保留两侧、上下留白。
